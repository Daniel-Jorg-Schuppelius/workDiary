Aquí administras los plugins e integraciones instalados (p. ej. Toggl,
OpenProject, Lexoffice, soporte remoto). Los plugins se controlan
**por organización**: activación, configuración, estado de salud y
errores valen solo para tu organización. En la lista ves estado y
salud y puedes configurar, activar/desactivar, ejecutar un
health-check o reactivar tras una desactivación automática; con
**Probar conexión** verificas la configuración sin guardar. Si un
plugin falla repetidamente se **desactiva automáticamente** solo para
la organización afectada; tras corregir la causa, restablece el
contador de errores y reactívalo. El registro de errores muestra cada
incidencia con detalle y permite marcarla como **confirmada**; revisa
el estado de salud después de cada cambio de configuración.
