Las categorías de gastos agrupan desembolsos y gastos de viaje, como
alojamiento, manutención, desplazamientos o material; cada categoría
tiene un slug, una denominación, un color y un tipo impositivo
predeterminado. Con los interruptores se controla si una categoría es
facturable por defecto y si requiere justificante; el tipo impositivo se
propone al registrar gastos nuevos. Las categorías inactivas se
conservan pero dejan de ofrecerse; una categoría aún usada por gastos no
puede borrarse — márquela como inactiva.
