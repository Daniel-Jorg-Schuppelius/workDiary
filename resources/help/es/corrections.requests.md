Mediante solicitudes de corrección puede registrar fichajes olvidados o
erróneos sin ocultar registros existentes con contraasientos. Una
solicitud agrupa, para una fecha, una justificación y posiciones
individuales que crean, modifican o eliminan un registro de tiempo o una
presencia; primero se crea como borrador. Recursos Humanos y los jefes de
equipo pueden, con el permiso correspondiente, corregir en nombre de
otras personas. Según la configuración de la organización, las
solicitudes enviadas pasan por aprobación o se aplican directamente como
autocorrección; las correcciones aplicadas se marcan siempre como
registro manual para mantener la trazabilidad. Los borradores y las
solicitudes enviadas pueden retirarse.
