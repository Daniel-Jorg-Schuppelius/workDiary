El módulo ISMS reúne todo lo necesario para un sistema de gestión de
seguridad de la información vivo; la certificación siempre la realizan
entidades independientes. El camino típico: definir el **alcance**
(cada organización parte de «Organización completa»), cargar el
catálogo de requisitos y declarar la aplicabilidad (SoA), mantener
**medidas** neutrales respecto a las normas, evaluar **riesgos** en la
matriz 5×5, realizar **auditorías** con hallazgos y acciones
correctivas y gestionar el estado de **certificación** por norma. La
**preparación para auditoría** ofrece indicadores por alcance con
enlaces a cada registro, y las páginas de registro incluyen
exportaciones JSON/CSV. El módulo forma parte del plan Enterprise;
lectura con permisos de lectura ISMS, cambios con permisos de gestión
ISMS.
