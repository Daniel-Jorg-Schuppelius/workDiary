Esta sección reúne las herramientas de protección de datos de toda la
organización (protegida por el permiso correspondiente). Ofrece un
resumen de miembros, sesiones y tokens de API, las categorías de datos
con plazos de conservación, y tablas de sesiones activas y tokens que
puedes **revocar** con efecto inmediato. También muestra los últimos
exportes de inquilino y accesos de soporte, y genera un informe
legible por máquina (JSON/CSV) como base para solicitudes de acceso y
portabilidad (art. 20 RGPD). Revocar sesiones o tokens puede
interrumpir integraciones en curso, y el exporte contiene datos
personales: trátalo de forma confidencial.
