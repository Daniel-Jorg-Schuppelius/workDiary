El soporte remoto importa informes de sesión de AnyDesk y TeamViewer y
los convierte en registros de tiempo, asignando cada sesión a un
activo mediante el ID del dispositivo. Las sesiones cuyo ID aún no
está asignado se acumulan en la bandeja de entrada, agrupadas por
proveedor y dispositivo. Allí puedes **asignar a un dispositivo
existente**, **crear un dispositivo nuevo**, **asignar sesiones
individuales** en dispositivos compartidos entre varios clientes, o
**descartar** grupos o sesiones sueltas. Las sesiones descartadas se
eliminan definitivamente y no se convierten en registros de tiempo; la
bandeja está reservada a administradores.
