Las etiquetas son un sistema genérico de clasificación que puede
adjuntarse a distintas entidades, como entradas de diario, turnos o
asignaciones; cada etiqueta tiene un nombre único y opcionalmente un
color. Elija un nombre expresivo, use el color para destacar la etiqueta
en listas y entradas, y consulte en la vista general cuántas veces se
usa cada una. Evite duplicados con grafías ligeramente distintas para
que la clasificación siga siendo analizable; las etiquetas que ya no se
necesitan pueden borrarse, eliminándose entonces sus asignaciones.
