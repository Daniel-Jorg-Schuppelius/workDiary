Las categorías de eventos clasifican eventos y citas: cada una tiene una
denominación, un color y opcionalmente una descripción, y aporta la
clasificación funcional para la gestión de eventos. Si una categoría
puede exigir un justificante, se activa la obligación de certificado y
se define una validez en meses; los plazos de recordatorio controlan
cuándo se avisa de justificantes a punto de caducar. Las categorías
inactivas se conservan pero dejan de ofrecerse; la denominación genera
automáticamente un nombre corto para la asignación interna.
