La check-list d'intégration guide une nouvelle organisation vers
l'exploitation productive en **étapes prédéfinies** ; les étapes accomplies
sont détectées automatiquement à partir des données — rien à cocher
manuellement. Étapes obligatoires (non contournables) : **données de
l'organisation** (nom, fuseau horaire, locale), **vérification des rôles**
(au moins 1 admin + 1 opérateur), **premier client**, **premier projet ou
ordre**. Les étapes recommandées peuvent être ignorées avec une
**justification**, consignée dans le journal d'audit ; le widget du tableau
de bord peut être masqué une fois les étapes essentielles terminées.
