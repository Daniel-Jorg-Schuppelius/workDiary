Les dimensions de temps libres étendent la répartition du temps avec
des cibles personnalisées qui n'existent pas comme modèle WorkDiary —
p. ex. commandes ERP ou objets de facturation internes. Les données de
base existantes (projets, centres de coûts, sites, véhicules,
activités) sont toujours référencées directement, jamais dupliquées.

Un type de dimension regroupe des valeurs sous un nom et un code. Les
types désactivés disparaissent du dialogue de répartition ; les
répartitions existantes restent inchangées. Les valeurs peuvent porter
une période de validité. L'ID externe ancre une future synchronisation
automatique ; d'ici là, la maintenance est manuelle et auditée.
