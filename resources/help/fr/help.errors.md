Lorsque WorkDiary ne peut pas afficher une page, une page d'erreur apparaît
à la place du contenu. Elle indique la raison, propose un retour et, si
c'est utile, « Signaler un problème ». L'identifiant de requête affiché
aide votre administration à retrouver l'événement dans le journal.

## Accès refusé {#forbidden}

Votre compte ne dispose pas de l'autorisation nécessaire pour cette page ou
cette action. Les autorisations dépendent de votre rôle dans
l'organisation. Si la page indique une raison précise (par exemple un
document verrouillé), celle-ci s'applique. Adressez-vous à votre
administration si vous avez besoin de cet accès pour votre travail.

## Page introuvable {#not-found}

L'adresse ne mène à aucun contenu. Causes fréquentes : l'enregistrement a
été supprimé ou fusionné, le lien est obsolète ou il appartient à une autre
organisation. Ouvrez l'entrée depuis la liste ou par la recherche.

## Session expirée {#session-expired}

Le formulaire est resté ouvert trop longtemps, ou vous vous êtes
déconnecté puis reconnecté dans un autre onglet entre-temps. Pour des
raisons de sécurité, il n'est alors pas enregistré. Rechargez la page et
envoyez à nouveau le formulaire ; copiez d'abord les textes longs dans le
presse-papiers.

## Fonction non incluse dans votre offre {#plan-locked}

La fonction fait partie d'un module que votre organisation n'a pas
souscrit. Votre administration voit les modules inclus dans l'aperçu de la
licence, où un changement d'offre peut être demandé.

## Erreur serveur {#server-error}

Une erreur inattendue s'est produite pendant le traitement. Dans ce cas,
vos saisies n'ont pas été enregistrées. Réessayez après un court instant.
Si l'erreur persiste, signalez-la via « Signaler un problème » : le
signalement contient l'identifiant de requête qui permet d'en trouver la
cause.

## Zone en maintenance {#area-maintenance}

Votre administration a temporairement verrouillé cette zone, par exemple
pour une reprise de données. Si la date est connue, la page indique quand
la zone sera de nouveau disponible. Les autres zones restent utilisables.
