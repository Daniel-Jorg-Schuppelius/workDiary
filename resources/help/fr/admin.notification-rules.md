Les règles de notification définissent, par type d'événement, **qui**
est informé sur **quels canaux** et quand une escalade a lieu. Ouvrez
un événement dans la liste, choisissez les **canaux** (« In-App »,
« E-mail », « Push »), définissez les **destinataires** (personne
concernée, rôles, destinataires supplémentaires) et, pour les
événements de retard, une **escalade** optionnelle après 1 à 720
heures. Sans règle propre, les valeurs par défaut du code s'appliquent
— ne configurez que les cas divergents. La modification est réservée
aux administrateurs de l'organisation.
