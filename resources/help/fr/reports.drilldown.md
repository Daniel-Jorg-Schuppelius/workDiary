Chaque indicateur des rapports est cliquable : le drill-down affiche les
**interventions concrètes** entrées dans le calcul, avec tous les
filtres actifs. Les colonnes montrent client, type d'entrée, statut et
durées prévue/réelle, le tri par défaut est par date décroissante, et
l'**export** CSV ou PDF crée un instantané avec filtres et horodatage
dans le nom de fichier. Le drill-down respecte votre périmètre
d'organisation et les statuts visibles : ce que vous ne pouvez pas voir
dans la liste n'est pas compté non plus dans le rapport global.
