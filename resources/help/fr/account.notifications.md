Le centre de notifications regroupe tous les avis qui vous sont adressés ;
il n'affiche que vos propres notifications et le nombre d'entrées non lues
est indiqué séparément. Vous pouvez marquer une notification comme lue ou
toutes d'un coup ; si une notification pointe vers une cible dans
WorkDiary, son ouverture vous y mène directement, les liens externes
n'étant pas suivis pour des raisons de sécurité. L'envoi par e-mail et les
plages de silence se règlent dans les paramètres de notification de votre
profil, sans effet sur la collecte dans le centre de notifications.
