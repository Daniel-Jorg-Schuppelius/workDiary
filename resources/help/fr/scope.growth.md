La page **Étendre le périmètre fonctionnel** affiche chaque module avec son
état et l'étape suivante adaptée. C'est le chemin à suivre quand votre
entreprise grandit et souhaite ajouter une fonction.

## États

- **Inclus, désactivé** — votre licence contient le module, votre
  organisation l'a désactivé. « Configurer » l'active immédiatement.
- **Nouveau dans votre licence** — le module a été ajouté à la licence après
  votre configuration. En mode « volontairement limité », il reste désactivé
  jusqu'à ce que vous le configuriez ici.
- **Non licencié** — la page indique le pack ou le lot qui contient le
  module. L'activation passe uniquement par une nouvelle licence.
- **Bloqué** — désactivé par la configuration système ; non modifiable ici.

## Ce que fait « Configurer »

- Le module est activé ; la barre latérale, les actions rapides et le
  catalogue des fonctions affichent de nouveau ses entrées.
- Si un espace de travail compact appartient au module, il est **ajouté** aux
  espaces proposés — rien n'est remplacé, les espaces personnels et les pages
  d'accueil restent.
- L'aperçu indique les dépendances. S'il manque un prérequis, configurez
  d'abord le module requis.
- Aucune donnée n'est modifiée et aucune licence n'est touchée.

## Demander une activation

Pour les modules non licenciés, communiquez à votre interlocuteur
l'identifiant de liaison de votre organisation. Rien n'est commandé ni envoyé
automatiquement ; vous installez la nouvelle licence via la gestion des
licences.

## Nouvelle configuration par défaut

S'il existe une configuration plus récente pour votre pack, la page affiche
un avis. Elle n'est appliquée que si vous la confirmez dans la configuration.
