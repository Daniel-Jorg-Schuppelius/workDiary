## Objectif et contexte

Les procès-verbaux documentent les travaux de façon probante sur la
commande — de la maintenance à la réception signée. Un procès-verbal
naît toujours **sur la commande**, jamais isolé : chaque documentation
reste rattachée à son dossier et se retrouve dans le dossier client.

## Prérequis

- Une commande, un projet ou un objet existant.
- En option, un **modèle** adapté (p. ex. « Réception », « Maintenance »).
  Les modèles sont créés à partir d’un protocole type via
  **« Enregistrer comme modèle »** et gérés dans l’administration sous
  **Modèles de protocole**.
- Le droit de créer des protocoles.

## Déroulement recommandé

1. Ouvrez la commande, le projet ou l’objet et choisissez
   **« Créer un protocole »**.
2. Choisissez le type, le titre et, si besoin, le **modèle** — il apporte
   ses points.
3. Ajoutez d’autres points via **« Ajouter un élément »** et saisissez chaque
   point via **« Renseigner l'élément »** : texte, oui/non, choix, mesure, défaut.
4. Joignez des **photos avant/après** au point concerné.
5. Soumettez le protocole **pour vérification** ou clôturez-le avec
   **« Finaliser / signer »** ; les clients reçoivent le **lien de signature**.

Dans la boîte de dialogue, vous attribuez aussi des **tags** ; ils figurent
ensuite dans les données de base du protocole. Les fichiers qui concernent
tout le protocole – un plan de situation, un bon de livraison – se téléversent
sur la page de détail sous **Pièces jointes**. Avec **Réorganiser les
points**, vous faites glisser les points dans l'ordre souhaité ; les
sous-points restent dans leur groupe. Tags, pièces jointes et ordre ne se
modifient que dans le brouillon ; chaque pièce jointe et chaque réorganisation
figure dans l'**Historique**.

Le lieu de prise de vue d'une photo n'est repris que si l'organisation l'a
activé sous **Paramètres → Téléversements** (par défaut : désactivé). Les
coordonnées sont visibles pour les personnes disposant du droit
correspondant ; elles sont toujours supprimées du fichier image.

## Exemple pratique

Après l'entretien d'un chauffage, le monteur remplit le modèle
« maintenance » directement devant l'appareil, photographie la vanne
remplacée sur le bon point et fait signer le client dans le dialogue
de signature — documenté avant même de démarrer le véhicule.

## Erreurs fréquentes

- **Laisser des points obligatoires ouverts :** ils sont marqués dans
  l'éditeur et doivent être remplis avant le passage à **En
  vérification**.
- **Joindre les photos « n'importe où »** au lieu du point concerné —
  le contexte se perd.
- **Chercher une documentation isolée :** les procès-verbaux tiennent
  volontairement à la commande ; créez d'abord l'entrée, documentez
  ensuite.

## Effets et prochaines étapes

L'enregistrement laisse un brouillon dans le dossier ; la signature en
fait la preuve opposable. Ensuite : recueillir la signature (voir
« Signer un procès-verbal ») et faire avancer le statut de la
commande.
