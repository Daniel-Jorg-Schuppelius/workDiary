La page des métriques affiche en lecture seule des indicateurs
d'exploitation et de performance : version de l'application, file
d'attente (jobs en attente/échoués), sauvegardes récentes, erreurs de
plugins, utilisation du stockage, utilisateurs actifs, volumes par
module et utilisation des fonctionnalités. Les valeurs sont relevées à
chaque appel ; les sections indisponibles retombent sur des valeurs
vides sans bloquer la page. L'accès exige le droit métriques ; les
contrôles de santé détaillés se trouvent sous **Diagnostic**.
