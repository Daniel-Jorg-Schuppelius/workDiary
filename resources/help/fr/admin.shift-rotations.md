Un plan de rotation est un rythme de service sur plusieurs semaines (p. ex.
deux semaines en alternance matin/soir) qui se prolonge automatiquement.
Dans la grille hebdomadaire, vous définissez le type de poste par semaine
et jour ; les jours sans entrée restent libres.

Les affectations ancrent le rythme par employé à une semaine de référence
(lundi de la semaine 1) ; les dates de validité facultatives limitent la
période. L'exécution quotidienne crée des services en brouillon pour la
fenêtre de planification — le report peut aussi être lancé manuellement.

La pré-planification est volontairement subordonnée : les services déjà
planifiés (y compris modifiés manuellement) et les absences approuvées ne
sont jamais écrasés ; le plan de rotation ne comble que les vides.
