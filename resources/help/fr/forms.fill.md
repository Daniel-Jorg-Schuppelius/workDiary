Avec les formulaires, vous remplissez des check-lists et des saisies
configurables que votre organisation a définies comme modèles. La vue
d’ensemble se trouve sous **Activité quotidienne** → **Savoir et
documents** → **Formulaires**.

Déroulement type :

1. Cliquez sur **Remplir le formulaire** et choisissez un modèle – seuls
   sont proposés les modèles au statut « Actif » dont la période
   (**Valable à partir du**/**Valable jusqu'au**) inclut la date du jour.
2. **Remplir les champs** : selon le modèle, par exemple Texte, Texte
   multiligne, Nombre, Date, Choix, Case à cocher, Photo ou Signature ;
   les champs obligatoires sont signalés, parfois avec un texte d’aide et
   une unité. Certains champs n’apparaissent que lorsqu’un autre champ
   a une valeur donnée.
3. La **Référence** découle de l’endroit où vous commencez : via la carte
   **Formulaires** sur la page de détail d’une mission, le formulaire est
   rattaché à cette mission ; seuls y sont proposés les modèles dont
   l’affectation (type de mission, client) correspond à la mission.
   Lancé depuis la vue d’ensemble **Formulaires**, le formulaire n’a pas
   de référence. Vous ne choisissez pas la référence vous-même.
4. **Envoyer** – le formulaire rempli est enregistré avec un horodatage
   et votre nom.

Sécurité des versions : lors de l’envoi, la définition des champs du
modèle est **figée sous forme d’instantané**. L’affichage et l’impression
utilisent toujours cet instantané – les modifications ultérieures du
modèle (voire sa suppression) ne modifient jamais votre formulaire rempli
après coup. Dans la vue d’un formulaire, **Imprimer** et **Télécharger le
PDF** sont disponibles.

Autorisations : peut remplir des formulaires toute personne disposant du
droit **Remplir des formulaires**. Dans la vue d’ensemble, les personnes
disposant du droit **Voir les modèles de formulaire** (par exemple les
chefs d’équipe) voient tous les formulaires remplis, les autres
uniquement les leurs.

Étapes suivantes : il manque un champ ou un modèle ? Adressez-vous au
chef d’équipe – il gère les **Modèles de formulaire**.
