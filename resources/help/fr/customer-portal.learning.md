Sur la page **Formations**, vous trouvez les cours que votre prestataire a
publiés pour les clients. Vous consultez l'aperçu des cours, vous vous
inscrivez ou les réservez, suivez les unités d'apprentissage et terminez le
cours.

## La vue d'ensemble des cours

Chaque cours apparaît sous forme de carte avec son titre et, le cas échéant,
son sous-titre et sa catégorie. Selon le cours, la carte affiche aussi le
**Prix** et une note en étoiles : la moyenne des retours sur le cours sur une
échelle de 1 à 5, visible seulement à partir de cinq réponses. S'il existe
plusieurs catégories, filtrez la liste en haut sous **Catégorie** ; **Toutes
les catégories** affiche de nouveau tout.

Si vous êtes déjà inscrit, la carte affiche votre statut et le bouton
**Ouvrir le cours**. Les statuts possibles sont **Attribué**, **En cours**,
**Terminé**, **Échoué**, **Expiré** et **Annulé**.

Si la page affiche **Aucune formation n’est actuellement ouverte pour
vous.**, aucun cours n'est disponible pour vous pour le moment.

## Aperçu

Si un cours comporte des unités d'aperçu, **Aperçu** ouvre l'**Aperçu du
cours** sans inscription : la description du cours et les textes des unités
d'aperçu. Les médias, les examens et les exercices ne font pas partie de
l'aperçu. Pour les cours en accès libre, vous vous y inscrivez directement
avec **S'inscrire au cours** ; **Retour** vous ramène à la vue d'ensemble.

## S'inscrire ou réserver

Le cours détermine comment vous le commencez :

- **S'inscrire au cours** – pour les cours en accès libre. Vous êtes inscrit
  immédiatement et le cours s'ouvre.
- **Réserver le cours** – pour les cours réservables. Le portail envoie une
  demande de réservation et confirme **Demande envoyée.** Votre prestataire
  statue sur celle-ci ; après son accord, vous êtes inscrit et la carte
  affiche **Ouvrir le cours**. Un nouveau clic ne crée pas de seconde
  demande. Le prix affiché est figé lors de l'accord.
- Si la carte affiche **L’inscription est effectuée par votre
  interlocuteur.**, seul votre prestataire peut vous inscrire.

Un cours n'apparaît dans la vue d'ensemble que pendant sa période de
disponibilité. Une inscription existante reste accessible au-delà.

## Suivre le cours

**Ouvrir le cours** affiche les unités d'apprentissage dans leur ordre avec
leurs textes. Une coche signale les unités terminées. Lorsque vous avez
travaillé une unité, cliquez sur **Marquer comme terminé**.

Des unités peuvent être verrouillées :

- **Disponible à partir du …** – l'unité n'est déverrouillée qu'à cette date.
- **Après l'unité précédente** – le cours suit un ordre fixe ; terminez
  d'abord l'unité précédente.

Si une unité impose une durée minimale, elle ne peut être terminée qu'une fois
cette durée écoulée ; le portail indique alors les minutes restantes. Si votre
accès est limité dans le temps et a expiré, vous ne pouvez plus terminer
d'unités.

## Achèvement

Lorsque toutes les unités obligatoires sont terminées, le cours est
considéré comme achevé. La page du cours affiche alors **Vous avez terminé ce
cours. La preuve est disponible pour le donneur d’ordre.** et le statut
indique **Terminé**. L'achèvement est documenté et traçable pour votre
prestataire.

## Limites

- Vous ne voyez que les cours publiés et expressément destinés aux clients.
  Si un cours attendu manque, adressez-vous à votre interlocuteur.
- Dans le portail, la page du cours affiche les textes des unités ; les
  médias et les examens n'y figurent pas.
- Vous ne pouvez ni vous désinscrire ni retirer une demande de réservation
  dans le portail.
