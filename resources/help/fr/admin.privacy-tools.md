Cette page regroupe les outils de protection des données de toute
l'organisation (accès protégé par le droit correspondant) : aperçu des
membres actifs, sessions et jetons API, catégories de données avec
sensibilité et durées de conservation. Les sessions actives et les
jetons API peuvent être **révoqués** — l'effet est immédiat et peut
interrompre des intégrations en cours. Les journaux tracent les
exports de tenant et les accès support, et l'export de données génère
un rapport JSON/CSV lisible par machine comme base des demandes
d'accès et de portabilité (art. 20 RGPD). Traitez cet export de
manière confidentielle.
