Dans le profil, vous gérez vos données personnelles (nom, e-mail, avatar,
coordonnées) ainsi que l'apparence et le comportement de l'interface :
thème, langue, fuseau horaire, formats de date et d'heure, page d'accueil
après connexion et paramètres globaux de notification. Le changement de
mot de passe se fait dans une boîte de dialogue dédiée et exige la
confirmation du mot de passe actuel, sauf lors d'une première définition
ou d'un changement forcé. Le modèle de temps de travail définit vos heures
théoriques pour les comptes de temps et les rapports ; l'abonnement au
calendrier fournit vos rendez-vous sous forme de flux ICS, dont le lien
d'accès peut être régénéré ou révoqué à tout moment.

Seules les pages que vous pouvez ouvrir sont proposées. Sans choix personnel,
la page d'accueil définie par votre organisation pour votre rôle s'applique.

Le plus rapide pour passer en mode sombre est **Paramètres** dans
l'en-tête. Les détails figurent dans la rubrique **Interface et affichage**.

## Signature e-mail

Sous **E-mail**, vous enregistrez votre signature pour les réponses envoyées
depuis WorkDiary (réponse à une note e-mail, réponse dans un ticket). Si le
champ reste vide, votre nom et l’organisation figurent sous la réponse. Le pied
de page e-mail de l’organisation (raison sociale, adresse, mentions
obligatoires) suit automatiquement ; l’administration de l’organisation le gère
dans les paramètres.
