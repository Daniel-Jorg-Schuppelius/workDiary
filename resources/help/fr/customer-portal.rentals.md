Sous **Location**, vous voyez vos locations en cours et terminées avec les appareils, la période et le statut.

Avec **Demande de location**, vous demandez des appareils pour une période. Si la réservation directe est activée, vous réservez immédiatement les appareils disponibles ; sinon, le loueur confirme la demande. Le prix affiché est une estimation issue de la liste de prix.

Si des conditions de location doivent être signées, vous les trouverez sous **Accords**.
