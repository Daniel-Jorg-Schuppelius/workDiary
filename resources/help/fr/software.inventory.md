La gestion des logiciels tient l'inventaire des logiciels et licences
utilisés : nom, éditeur, type (système d'exploitation, application,
firmware, pilote, service ou autre) et type de licence, avec un statut
actif pour les logiciels en usage. La vue d'ensemble affiche le nombre
d'installations par logiciel et permet la recherche, le filtrage par
type et le tri ; la création et la modification se font dans une boîte
de dialogue. Un logiciel ne peut pas être supprimé tant que des
installations lui sont associées — retirez d'abord les affectations. Ce
module est indépendant de la saisie logicielle dans le SMSI.
