Sous **Documents**, vous trouvez les documents que votre prestataire a
expressément publiés pour votre entreprise, par exemple des rapports de
contrôle, des certificats, des contrats ou des manuels. Vous pouvez les y
télécharger à tout moment.

## La liste

Le tableau affiche pour chaque document :

- **Titre** – la désignation du document.
- **Type** – le type de document : **Contrat**, **Rapport de contrôle**,
  **Certificat**, **Manuel**, **Fiche technique**, **Document fabricant**,
  **Autorisation**, **Assurance**, **Facture** ou **Autre**.
- **Valide jusqu’au** – la date d'expiration si le document en a une (par
  exemple un certificat ou une autorisation) ; sinon la colonne affiche « — ».
- **Publié le** – le jour où votre prestataire a publié le document pour vous.

Les documents publiés le plus récemment figurent en haut. Chaque page affiche
25 documents ; utilisez la pagination en bas de page pour voir les suivants.

## Télécharger un document

Cliquez sur **Télécharger** dans la ligne. Vous recevez toujours la version
actuelle du document avec son nom de fichier d'origine. Si seul « — »
apparaît à cet endroit, aucun fichier n'est encore disponible pour ce
document.

## Poser une question sur un document

Si l'espace **Questions** est également ouvert pour votre entreprise, le
bouton **Question** apparaît à côté de **Télécharger**. Il vous permet de
poser une question ou de laisser un commentaire sur exactement ce document ;
la réponse de votre prestataire apparaît sous **Questions**.

## Quels documents apparaissent

- Uniquement les documents que votre prestataire a expressément publiés sur
  le portail client. Les documents internes restent masqués.
- Uniquement les documents rattachés à votre entreprise elle-même ou à vos
  projets, missions et objets.
- Si votre prestataire retire une publication, le document disparaît de la
  liste et ne peut plus être téléchargé.

## Limites

Dans le portail, vous ne pouvez ni déposer, ni modifier, ni supprimer de
documents. Si un document attendu manque, il n'a pas encore été publié pour
vous ; adressez-vous à votre interlocuteur. L'espace n'apparaît que s'il est
ouvert pour votre entreprise.
