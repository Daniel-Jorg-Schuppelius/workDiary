L'auto-évaluation vous permet de demander des informations aux
fournisseurs, par exemple sur les certificats, la durabilité ou la
protection des données. Vous gérez les questionnaires sous « Fournisseurs
→ Auto-évaluation » ; les questions se composent de champs comme pour les
modèles de formulaire. Une validité en mois fixe la durée pendant laquelle
une auto-évaluation acceptée reste valable.

## Envoyer une demande

Dans le dossier fournisseur, « Demander une auto-évaluation » ouvre
l'envoi. Le fournisseur reçoit par e-mail un lien valable 30 jours et
remplit le questionnaire sans se connecter. Les questions sont figées pour
chaque demande : les modifications ultérieures du questionnaire ne changent
pas les réponses données. Une demande ouverte pour le même questionnaire
est retirée lors d'un nouvel envoi.

## Vérifier les réponses

Vous voyez les auto-évaluations soumises dans la demande. Acceptez-les ou
renvoyez-les pour correction. L'évaluation interne des fournisseurs dans
l'ISMS reste distincte.
