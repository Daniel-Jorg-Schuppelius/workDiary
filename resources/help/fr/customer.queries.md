Les clients posent, via le portail ou le **lien de signature**, des
questions sur un dossier présenté (procès-verbal, réception, commande) ;
chaque question apparaît ici comme entrée traçable et déclenche une
notification au rôle compétent. Les questions **ouvertes** figurent en
haut : **Répondre** enregistre une réponse visible par le client via le
même lien, **Clôturer** marque une question réglée sans réponse écrite
(par ex. clarifiée par téléphone). Via le lien de signature, le client
peut aussi **refuser** le dossier avec justification obligatoire ; les
défauts signalés sont alors créés automatiquement comme **points
ouverts** (source « refus client », visibles par le client) sur la
commande ou le procès-verbal concerné. Approbation comme refus sont
consignés avec horodatage de manière infalsifiable.
