Gérez ici les modèles d'étiquettes et générez des étiquettes imprimables
pour variantes, lots et numéros de série. Un modèle définit le format de
papier (A6, A7, A8), l'orientation, le code QR optionnel et les champs
affichés ; une seule étiquette par organisation peut être le modèle par
défaut — en définir un nouveau réinitialise l'ancien. L'étiquette est
produite en PDF avec le code scannable (numéro de série, lot ou SKU) ;
sans modèle choisi, le modèle par défaut ou une configuration standard
minimale est utilisée. La gestion des modèles requiert le droit de
configuration.
