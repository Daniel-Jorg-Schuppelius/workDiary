Démarrez une nouvelle saisie de temps via le bouton **« Nouvelle
entrée »** dans la barre supérieure ou via le chronomètre. Champs
obligatoires dans le MVP : heure de début, projet ou client, catégorie
d'activité. Laissez la fin ouverte tant que vous travaillez — le
chronomètre continue de tourner. Les pauses se saisissent séparément
dans la vue de clôture de journée, pas dans la saisie de temps.
