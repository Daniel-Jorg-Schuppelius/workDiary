L'inscription crée une nouvelle organisation avec son premier compte
administrateur : indiquez le nom de l'organisation, votre nom, une adresse
e-mail et un mot de passe, puis validez — vous êtes connecté directement.
La nouvelle organisation démarre avec l'offre gratuite ; des fonctions et
modules supplémentaires s'activent plus tard via une licence.
L'inscription n'est disponible que si elle est explicitement activée dans
la configuration ; sinon, les nouvelles organisations sont créées par
l'administration.
