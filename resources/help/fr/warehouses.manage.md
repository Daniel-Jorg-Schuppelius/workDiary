Vous créez ici les entrepôts et emplacements qui portent les stocks,
l'inventaire et les mouvements. La liste affiche les emplacements avec
le nombre de mouvements associés, l'emplacement par défaut en premier.
Un emplacement comporte essentiellement un nom et un code ; un seul
peut être marqué comme défaut, et la création comme la modification se
font dans une boîte de dialogue. Un emplacement ne peut être supprimé
que tant qu'aucun mouvement n'y existe — créez-les donc avec soin, car
ils ne peuvent plus être retirés après les premières écritures.
