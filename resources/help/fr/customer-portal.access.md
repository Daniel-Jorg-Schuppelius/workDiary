Votre accès au portail client est un compte personnel que votre prestataire crée pour vous. Cette rubrique explique comment activer l'accès, vous connecter, modifier votre e-mail de connexion et protéger l'accès par un second facteur.

## Activer votre accès

Votre prestataire vous invite par e-mail ; l'objet est « Votre accès au portail client de … ». L'e-mail contient le bouton **Définir le mot de passe**. Le lien ne peut servir qu'une fois et reste valable sept jours ; la date d'expiration figure dans l'e-mail.

1. Cliquez dans l'e-mail sur **Définir le mot de passe**.
2. Saisissez un mot de passe dans **Nouveau mot de passe** et répétez-le dans **Répéter le mot de passe**.
3. Cliquez sur **Enregistrer le mot de passe**.

Le mot de passe doit comporter au moins 12 caractères, avec majuscules et minuscules, chiffres et caractères spéciaux. Les mots de passe issus de fuites de données connues sont refusés. La page de connexion s'ouvre ensuite avec le message **Votre mot de passe a été défini. Vous pouvez maintenant vous connecter.**

Si le lien a expiré, la page ne s'ouvre plus. Demandez alors à votre prestataire de vous renvoyer l'invitation.

Si votre prestataire a réinitialisé votre accès, votre mot de passe précédent n'est plus valable et toutes les sessions de votre accès sont fermées. Vous recevez alors une nouvelle invitation avec l'objet « Votre accès au portail client de … » et définissez à nouveau votre mot de passe comme décrit ci-dessus. Un second facteur déjà configuré est conservé.

## Se connecter

Sur la page **Se connecter**, saisissez votre **E-mail** et votre **Mot de passe**, puis cliquez sur **Se connecter**. Avec **Rester connecté**, vous n'avez pas à vous reconnecter à chaque visite sur cet appareil – n'utilisez cette option que sur votre propre appareil.

- Si l'e-mail ou le mot de passe est erroné, le message **Ces identifiants ne correspondent pas à nos enregistrements.** s'affiche. Pour des raisons de sécurité, le portail n'indique pas quelle donnée était fausse.
- Le nombre de tentatives de connexion est limité ; après trop d'échecs, vous devez patienter un moment.
- Si votre prestataire a désactivé votre accès, la connexion n'est plus possible.
- Si vous avez oublié votre mot de passe, réinitialisez-le vous-même via **Mot de passe oublié ?** sous le formulaire de connexion.

### Mot de passe oublié

1. Sur la page **Se connecter**, cliquez sur **Mot de passe oublié ?**.
2. Saisissez votre e-mail de connexion dans **E-mail** et cliquez sur **Envoyer le lien**.
3. Dans les 60 minutes, ouvrez le lien de l'e-mail dont l'objet est « Réinitialiser votre mot de passe du portail client de … » (bouton **Définir le mot de passe**).
4. Saisissez un mot de passe dans **Nouveau mot de passe**, répétez-le dans **Répéter le mot de passe** et cliquez sur **Enregistrer le mot de passe**.

Après l'envoi, le portail affiche toujours **Si un compte avec cet e-mail existe, un lien de réinitialisation a été envoyé.** – même s'il ne connaît pas l'adresse. Ainsi, personne ne peut savoir quelles adresses disposent d'un accès. Seuls les accès actifs reçoivent un e-mail : si votre invitation est encore en attente ou si votre accès a été désactivé, adressez-vous à votre prestataire. Le lien ne sert qu'une fois ; votre mot de passe actuel reste valable jusqu'à ce que vous enregistriez le nouveau. Si vous n'êtes pas à l'origine de la demande, ignorez simplement l'e-mail.

Le nouveau mot de passe obéit aux mêmes règles que lors de l'activation de l'accès. Après l'enregistrement, la page de connexion affiche **Mot de passe modifié. Veuillez vous connecter.** Toutes les sessions ouvertes de votre accès, y compris sur d'autres appareils, sont alors fermées. Un second facteur déjà configuré est conservé et demandé comme d'habitude lors de la prochaine connexion. Plusieurs demandes rapprochées sont limitées ; patientez alors un moment.

### Second facteur à la connexion

Si vous avez configuré un second facteur, la page **Confirmation à deux facteurs** suit le mot de passe. Selon la méthode configurée :

- saisissez dans **Code** le code à 6 chiffres de votre application d'authentification et cliquez sur **Confirmer**,
- cliquez sur **Envoyer le code par e-mail** et saisissez le code reçu ; puis **Confirmer avec le code e-mail**,
- connectez-vous avec **Avec passkey / clé de sécurité**,
- ou saisissez l'un de vos codes de récupération via **Utiliser plutôt un code de récupération**.

Après plusieurs codes erronés, la saisie est brièvement bloquée ; après trop d'échecs, la connexion recommence depuis le début. **Annuler** vous ramène à la page de connexion.

## Profil et e-mail de connexion

Sous **Profil**, dans la section **Votre accès**, vous voyez les données **Nom**, **E-mail de connexion** et **Client** – l'entreprise à laquelle votre accès est rattaché. Seul votre prestataire peut modifier le nom et l'entreprise.

Vous modifiez vous-même votre e-mail de connexion :

1. Sous **Modifier l’adresse e-mail**, saisissez la **Nouvelle adresse e-mail**.
2. Cliquez sur **Envoyer le lien de confirmation**. Si vous ne vous êtes pas
   connecté récemment, le portail demande d'abord votre mot de passe sous
   **Confirmer le mot de passe**.
3. Ouvrez dans les 24 heures le lien de l'e-mail envoyé à la nouvelle adresse.

Ce n'est qu'après le clic sur le lien que la nouvelle adresse devient votre e-mail de connexion ; l'ancienne adresse reçoit une information sur ce changement. D'ici là, vous vous connectez avec l'ancienne adresse, et le profil indique pour quelle adresse une confirmation est en attente et jusqu'à quand. Une nouvelle demande remplace celle en cours. Si la nouvelle adresse est déjà utilisée, aucun e-mail n'arrive ; le message du portail est identique dans tous les cas, afin que personne ne puisse tirer de conclusions sur d'autres comptes.

## Configurer l'authentification à deux facteurs

**Sécurité** ouvre la page **Authentification à deux facteurs**. En haut à droite figure l'état : **Active**, **Configuration en attente** ou **Inactive**. La section **Ajouter une méthode** propose trois méthodes ; vous pouvez en utiliser plusieurs en même temps.

### Application d'authentification

1. Cliquez sur **Afficher le code QR**.
2. Scannez le code QR avec votre application (par exemple Google Authenticator, Aegis ou 1Password) ou saisissez la **Clé** affichée.
3. Saisissez le code à 6 chiffres de l'application et cliquez sur **Confirmer**.

### Code e-mail

1. Cliquez sur **Activer le code e-mail**. Le portail envoie un code à votre e-mail de connexion.
2. Saisissez le code et cliquez sur **Confirmer**. Si aucun e-mail n'est arrivé, demandez un nouveau code avec **Renvoyer le code**.

### Clé de sécurité / passkey (FIDO2)

Cliquez sur **Ajouter une passkey** et suivez les instructions de votre navigateur ou de votre appareil – avec une passkey, votre smartphone ou une clé matérielle. Si votre connexion remonte à un certain temps, le portail vous demande d'abord votre mot de passe sur la page **Confirmer le mot de passe**.

### Codes de récupération

Lors de la configuration de la première méthode, le portail affiche une seule fois vos **Codes de récupération**. Chaque code fonctionne exactement une fois et remplace le second facteur à la connexion. Conservez ces codes en lieu sûr ; le portail ne les affiche plus. Si l'application d'authentification est configurée, vous pouvez générer un nouveau jeu : sous **Régénérer les codes de récupération**, saisissez dans le champ **Code d'application actuel** le code de l'application et cliquez sur **Générer**. Les anciens codes ne sont alors plus valables.

Si vous avez perdu toutes vos méthodes et vos codes de récupération, adressez-vous à votre prestataire. Il peut réinitialiser votre second facteur ; vous recevez alors un e-mail intitulé « Votre second facteur a été réinitialisé » et vous vous connectez ensuite uniquement avec votre mot de passe. Si l’authentification à deux facteurs est obligatoire, vous configurez alors une nouvelle méthode.

## Supprimer des facteurs ou tout désactiver

La section **Facteurs actifs** liste les méthodes configurées. Vous supprimez le code e-mail et les passkeys un par un avec **Supprimer** (icône de corbeille). L'application d'authentification ne peut être désactivée qu'avec tout le reste.

Sous **Tout désactiver**, vous coupez entièrement l'authentification à deux facteurs : saisissez un **Code d'application ou de récupération** et cliquez sur **Désactiver**. Tous les facteurs et codes de récupération sont alors supprimés.

## Lorsque l'authentification à deux facteurs est obligatoire

Votre prestataire peut exiger un second facteur pour tous les accès. Dans ce cas :

- Si vous n'avez pas encore de second facteur, le portail vous conduit après la connexion vers la page **Authentification à deux facteurs** avec le message **Votre organisation exige l'authentification à deux facteurs. Veuillez la configurer maintenant.** Les autres pages ne s'ouvrent qu'une fois une méthode configurée.
- Le dernier facteur restant ne peut pas être supprimé.
- **Tout désactiver** n'apparaît pas ; à la place, un message indique que la désactivation n'est pas possible.
