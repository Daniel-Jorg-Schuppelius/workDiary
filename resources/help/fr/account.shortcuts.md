De nombreuses parties de WorkDiary s'utilisent sans souris. Appuyez à tout
moment sur `?` — en dehors d'un champ de saisie — pour ouvrir l'aperçu de
tous les raccourcis. Ce même aperçu est accessible depuis ce texte d'aide.

Les raccourcis ne se déclenchent jamais pendant que vous tapez dans un
champ, une zone de texte ou une liste déroulante ; ils n'interfèrent donc
pas avec votre saisie.

Raccourcis globaux :

- `Ctrl`/`⌘` + `K` ouvre la recherche globale : pages, rubriques d'aide et
  actions comme « Changer le thème de couleurs », ainsi que clients, projets,
  frais, déplacements, collaborateurs … Dans la recherche, choisissez un résultat
  avec `↑`/`↓` et ouvrez-le avec `↵`.
- `Échap` ferme la recherche ou le dialogue ouvert.
- `?` affiche l'aperçu de tous les raccourcis.
- `F1` ouvre l'aide contextuelle de la page actuelle (barre d'aide de droite).

Les raccourcis de navigation sont de courtes séquences : d'abord `g` (pour
« aller à »), puis la touche cible dans la seconde qui suit.

- `g` puis `d` — journal
- `g` puis `k` — clients
- `g` puis `p` — projets
- `n` — nouvelle entrée

Les raccourcis de navigation n'apparaissent que si vous pouvez aussi
atteindre la cible par le menu. Sans ce droit, le raccourci reste muet et
n'est pas listé dans l'aperçu.
