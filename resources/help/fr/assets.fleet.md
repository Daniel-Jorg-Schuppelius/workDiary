Les équipements et véhicules représentent les objets de l'entreprise avec
statut, responsabilité, documents et informations de maintenance ; les
journaux de carburant et de charge complètent l'historique de consommation.
Via le panneau **« Remise / Retour »**, un appareil est remis à une
personne ou une équipe (une seule remise ouverte par équipement ; les
retards déclenchent une notification). Dans le panneau **« Défauts /
Blocages »**, vous saisissez les défauts avec gravité ; un défaut bloquant
empêche toute nouvelle remise jusqu'à sa résolution avec note obligatoire.
Le **« Dossier d'objet »** regroupe tout le cycle de vie dans une vue
imprimable (données de base, maintenances, remises, défauts, historique) —
accessible par le bouton dédié, impression directe avec « ?print=1 ».
