Cliquez sur le titre de la commande dans le journal pour ouvrir la vue
détaillée (dossier) ; la modification directe s'effectue dans les
différentes sections (commentaires, pièces jointes, temps,
procès-verbaux). Les classifications obligatoires doivent être remplies
avant le passage au statut **Terminé**. Les notes de communication sont
tenues chronologiquement sous la commande et restent visibles pendant
toute sa durée de vie. Les pièces jointes sont limitées à **25 Mo** ;
les fichiers plus volumineux doivent être référencés via un stockage
externe.
