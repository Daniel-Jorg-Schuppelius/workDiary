The module keeps general contracts (rent, maintenance, software, framework agreements) as dedicated files with term, notice period, renewal and indexation logic.

**Deadlines in view:** Termination and renewal dates trigger reminders through the notification rules (multi-level escalation, optional calendar channel), so no contract renews unnoticed.

**Obligations:** Recurring duties (payments, inspections, reports) are tracked per contract and appear in the calendar (menu “Calendar”), together with contract end, renewal and index review.

**Links:** Leasing/financing contracts from asset management can be attached to a contract; documents attach to the file as everywhere else.

**Note on an obligation:** For each contract obligation (deadline, duty) you can store a note, for example what has to be done or whom to inform.
