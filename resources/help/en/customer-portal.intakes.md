Under **Requests and orders** you request services and submit files.

- **Request print** or **Request IT service** opens a form with subject, description, requested date and the matching details. Where you are unsure, choose "Advice needed". Allowed formats and sizes are shown at the file field; if a file fails, it is named and nothing is saved halfway.
- After submitting you receive a reference number and a confirmation of receipt. It confirms receipt only — no order acceptance and no date.
- The **status** shows what is happening and what is needed from you next: answer a question, decide on a quote or approve print data.
- **Quote**: you see the offered items, select options if applicable and accept or reject. Your decision is documented with a timestamp.
- **Print approval**: you see the file, version, checksum and production parameters. Printing starts only after your approval and the internal check. A new file requires a new approval.
- **Submit files** attaches new files to an open request; existing files are never overwritten.

As long as no quote has been accepted, you can withdraw a request. The withdrawal is logged.

**Large files:** If an upload link is available, open a personal link with password on the request. There you can upload even very large files without seeing any other files. We transfer them automatically and check them by the same rules; "Transfer uploaded files now" does it immediately. The link ends when it expires or as soon as the request no longer accepts files.
