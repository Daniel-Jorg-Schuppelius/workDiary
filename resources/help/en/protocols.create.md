A protocol is always created **on a work order** – never standalone.
Open the case file and choose **"Generate protocol"** in the actions
menu.

Steps:

1. Pick a **template** (e.g. "Acceptance", "Commissioning",
   "Maintenance").
2. Work through the **protocol items**: text, choice, photo, reading.
3. Attach **before/after photos** to the respective item.
4. **Saving** keeps the protocol in **Draft** status. For acceptance,
   switch to the signature dialog afterwards.

Mandatory items are visually marked in the editor and must be filled in
before the status can change to **In review**.
