Entry types define the kinds of diary and job entries, such as service,
incident, maintenance or installation. Each type has a unique slug, a
label, an icon and a colour and provides the defaults for new entries.

The requirement and permission toggles control whether a type demands a
customer, address, schedule or tour, and whether priority or tour are
allowed. The default status, default service duration and default priority
are applied when an entry is created.

Inactive types no longer appear in the selection. A type that is still used
by entries cannot be deleted; set it to inactive in that case.
