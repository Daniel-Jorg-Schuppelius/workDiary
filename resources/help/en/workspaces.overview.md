A **workspace** is a switchable focus view: when someone picks a workspace in
the switcher (top of the header), the navigation shows only the matching areas.
This is **purely cosmetic** — no permissions, modules or data change, and
everything stays reachable via global search and **All functions**.

## What you set here

- **Offered workspaces:** which areas appear in the switcher. “Show
  everything” is always available.
- **Default:** the workspace new users start with.
- **Display name:** a custom name per workspace (optional).

## Only a suggestion

The default is **never forced on anyone**: everyone picks their workspace
freely and can switch any time. An installed industry profile may suggest a
fitting default as long as the organization does not set its own.

## Boundaries

- Hiding is **not** access control — deep links, search and permissions stay
  untouched.
- Whatever a workspace hides is marked under **All functions** and stays
  reachable there.
