Here you maintain the material and raw-material master data used in
manufacturing and inventory as well as when posting material usage.

A material carries, among other things, an SKU, a name, a unit, a default
unit price, a tax rate and an active status. The list can be searched and
sorted by these fields; an optional external provider can be recorded.

Creating and editing run as a dialog. When deleting a material, note that
it may be referenced in existing postings; check dependencies before
removing it, and prefer to set materials that are no longer needed to
inactive.
