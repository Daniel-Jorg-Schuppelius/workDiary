Idea maps are freely shaped canvases of nodes and connections — for
collecting, structuring and developing thoughts before they turn into
concrete work. Each map can optionally be linked to a customer or project
and grows from loose brainstorming into a structured outline.

**Private by default:** A new map is visible only to the person who created
it. It becomes visible to others solely through an explicit share with
individual people — either read-only or with editing rights. There is
deliberately no administrator override: even admins only see other people's
maps after being granted access. When someone leaves, ownership of a map can
be transferred deliberately so nothing is lost.

**Editing with conflict protection:** Create, rename, move, connect and
delete nodes — individually or as a whole map in one go. If several people
work at the same time, the first save wins; the second person receives a
notice along with the current state and can reapply their change on top of
it. There is no silent overwriting. Anyone currently working on the map is
shown as present, and the change history records what changed and when.

**Lifecycle:** Finished maps can be archived; deleted maps and nodes can be
restored from the trash.

**Turning ideas into work:** A matured node can be converted into a task, a
project or a knowledge article with one click. The conversion is idempotent:
triggering it again for the same node and target type does not create a
duplicate — there is exactly one target, and the link remains permanently
visible on the node. This keeps it traceable which idea led to which piece
of work.

**Import & export:** Existing mind maps can be imported from FreeMind or
OPML files; maps can be exported as JSON, OPML, Markdown or PDF — for
example to share them outside the system.
