Key handovers record to whom a key or key-bound object was issued and from
whom it was taken back. Each event is linked to an inventory item (asset) and
captures the direction (issue or return), the person involved, a reference,
and the time. An expected return time can optionally be noted.

In the overview you filter by asset, direction and person text and sort by
time or expected return. This makes it traceable which keys are currently
issued and who holds them.

A new event can be created directly from an asset's context so that the link
is pre-filled. Recording is available to people with the appropriate
permission.
