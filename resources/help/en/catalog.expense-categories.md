Expense categories group out-of-pocket and travel costs, such as lodging,
meals, travel or materials. Each category has a slug, a label, a colour and
a default tax rate.

The toggles control whether a category is billable by default and whether a
receipt is required. The stored tax rate is suggested when new expenses are
recorded.

Inactive categories are retained but no longer offered for selection. A
category that is still used by expenses cannot be deleted; set it to
inactive in that case.
