The module makes sustainability operationally manageable — without any
conformity claim or carbon-neutrality statement.

**Activity data & CO₂e:** consumption (electricity, heat, fuel, trips,
waste, water …) is recorded per period with data quality
(measured/calculated/estimated — estimates are always flagged).
Emission factors come from a versioned library (UBA/DEFRA-based default
set, organisation-overridable) with effective-date resolution, scope
assignment and source. A missing factor produces a warning instead of a
silent zero.

**Assessments:** devices, processes, services or suppliers are scored
against the organisation's E/S/G criteria catalogue (0–5, weighted, with
source and justification per criterion). Finalisation freezes score,
weights and methodology as a snapshot; changes create new versions. The
alternative comparison puts two assessments side by side.

**Measures & targets:** the measure register tracks expected impact,
effort, cost, deadline, evidence and the effectiveness review after
implementation. Target paths interpolate expected values per year.

**Report:** KPIs with drilldown, data-quality warnings, CSV export with
methodology note and a freezable management-review snapshot. The
VSME 1.0 reference matrix shows which WorkDiary data prepares which
report section.
