Event categories classify events and appointments. Each category has a
name, a colour and an optional description and provides the functional
grouping used in event management.

If a category requires proof of attendance, you can enable the certificate
requirement and set a validity period in months. Reminder lead times
control when expiring certificates are flagged.

Inactive categories are retained but no longer offered for selection. The
name automatically generates a short slug used for internal mapping.
