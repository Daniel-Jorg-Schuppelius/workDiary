API tokens let external programs access the WorkDiary interface on your
behalf without using your password. When creating one you assign a name
that helps you later associate the token with a purpose or device.

The actual token value is shown only once, directly after creation.
Copy it immediately and store it securely, because it cannot be viewed
again afterwards. In the overview you only see the name and creation
time of your existing tokens.

Important: an API token is a full access key to your account. Never
share it and transfer it only over secure channels. If you suspect
misuse or no longer need a token, revoke it immediately; a revoked
token can no longer be used right away.
