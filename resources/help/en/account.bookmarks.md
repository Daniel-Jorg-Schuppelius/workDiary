Bookmarks are personal shortcuts to pages within WorkDiary. Each
bookmark consists of a label and an address; optionally you can store
an icon and a sort order. You can search the list by label or address.
Bookmarks belong to you alone and are not visible to others.

Filter presets save recurring filter settings of a view so you do not
have to assemble them each time. Each preset is assigned to a scope and
can be marked as the default for that scope; only one preset per scope
counts as the default.

Both features are purely personal and independent of your
organization's data. You can create, edit and remove bookmarks and
presets at any time.
