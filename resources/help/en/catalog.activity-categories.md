Activity categories group work activities into reusable classes. Each
category has a technical key, a label and an activity type, and controls
whether the time counts as work and whether it is billable by default.

Set the key (lowercase letters, digits, hyphens) and the label. Toggle
"counts as work" and "billable by default" to match how the category is
used. Colour, icon and sort order determine the appearance in lists and
selection fields.

Inactive categories are retained but no longer offered for selection. The
search and column sorting help you locate entries quickly even in large
catalogues.
