Data transfer bundles import and export of data under a shared tab
navigation: **Import**, **Export** and **History**. All runs are
limited to the current organization.

Areas:

- **Import**: CSV import via the import wizard. See the **Import**
  chapter for details.
- **Export**: select an entity (e.g. customers) and a format;
  optionally narrowed by filters (status, search text, date range,
  user). The export is created as a run and is then available for
  download.
- **History**: import and export runs together, with status and
  metrics (e.g. row count).

Exports can later be downloaded or deleted; deleting also removes the
stored file.

Access is granted to admins or to anyone holding at least one export
permission for an entity. Every export is recorded in the audit log.

Note: this area is for data migration/transfer. For full system
backups see **Backups**.
