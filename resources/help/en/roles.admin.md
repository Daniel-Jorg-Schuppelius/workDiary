As the admin of your organization you set up WorkDiary, manage users
and permissions and keep operations healthy.

Typical flow:

1. **Users and roles**: create accounts, assign role profiles, make
   organization-specific adjustments in the role management.
2. **Master data and modules**: customers, projects, templates
   (protocols, forms, procedures) and module/plan activation.
3. **Maintain rules**: notification rules, surcharge rules, export
   profiles.
4. **Check operations**: backup heartbeat, system health, audit chain,
   plugin status.
5. **Escalations**: correction requests, locked accounts, 2FA resets.

What you can do: essentially everything within your organization –
including all write permissions. Which is exactly why:

- Before critical actions (delete, purge, unlock), check whether a
  functional path exists instead (correction request, void).
- The **global admin role** (platform-wide, without an organization) is
  reserved for the operator and is never assigned via the organization
  UI.

The complete reference is the **admin handbook** (related topics
below).
