The week view places **order-book entries**, **on-call shifts** and
**emergency assignments** on a calendar. It supports overview and
planning; it is not used to record working time.

How to use the view:

1. Select the required date range in the header.
2. Switch between **My week** and **Team week**. The team view also
   allows filtering by employee.
3. Select an existing entry to open its details.
4. Select free time in the calendar to create an order-book entry,
   on-call shift or emergency assignment.

Colors indicate order status, such as **Open**, **Problem**,
**Confirmed** or **Done**. Core and extended working-time bands are
visual guidance only.

Use time tracking or an active stopwatch to record actual working time.
