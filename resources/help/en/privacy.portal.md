The request portal lets data subjects exercise their rights without having an
account in the application — access, rectification, erasure, restriction,
portability and objection.

**Process:** The person submits the request on a public page. It arrives as a
case in the data protection area, not as an immediate result: whoever asks
must first be identified as the person concerned.

**Deadlines:** The statutory deadline starts on receipt. The case shows it and
reminds you in good time; an extension is possible but must be justified and
communicated to the person.

**Identity:** Verify identity before releasing data — when in doubt, ask rather
than answer. Disclosure to the wrong person is itself a data breach.

**Not the same as:** The request portal is not the whistleblowing portal. That
one is for reports about misconduct; this one is about the requester's own
data.
