The **Extend feature scope** page shows every module with its state and
the matching next step. It is the way to go when your company grows and
wants to add a function.

## States

- **Included, deactivated** — your license includes the module, your
  organization switched it off. "Set up" activates it immediately.
- **New in your license** — the module was added to the license after your
  setup. In "deliberately limited" mode it stays deactivated until you set
  it up here.
- **Not licensed** — the page names the package or bundle that includes the
  module. Activation only comes with a new license.
- **Blocked** — switched off by the system configuration; not changeable
  here.

## What "Set up" does

- The module is activated; sidebar, quick actions and function catalog show
  its entries again.
- If a compact workspace belongs to the module, it is **added** to the
  offered workspaces — nothing is replaced, personal workspaces and start
  pages stay.
- The preview names dependencies. If a requirement is missing, set up the
  required module first.
- No data is changed and no license is touched.

## Request activation

For unlicensed modules, tell your contact the binding ID of your
organization. Nothing is ordered or sent automatically; you install the new
license via license management.

## New default

If a newer default exists for your package, the page shows a notice. The
default is applied only when you confirm it in the setup.
