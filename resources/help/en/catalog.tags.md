Tags provide generic labelling that can be attached to various entities,
such as diary entries, shifts or assignments. Each tag has a unique name and
an optional colour.

Choose a meaningful name; the name must be unique. The colour lets you
highlight tags visually in lists and on entries. The overview shows how
often a tag is already in use.

Avoid near-duplicate spellings so that the labelling stays usable for
analysis. Tags that are no longer needed can be deleted; their assignments
are removed in the process.
