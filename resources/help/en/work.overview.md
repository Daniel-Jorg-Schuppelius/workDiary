The daily overview combines upcoming work, active time tracking,
appointments and personal notices. Kanban presents the same operational
entries grouped by processing status.

Typical flow:

1. Review due or recently changed items in **Today**.
2. Open an order, add information or start time tracking.
3. Use **Kanban** to filter entries and move them to the next permitted
   status.

If no entries appear, check the date range, filters and active
organization. Status changes use the same permissions and required
fields as the work list.
