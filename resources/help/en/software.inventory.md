Software management keeps the inventory of the software and licenses in use.
For each entry you maintain the name, vendor, kind (operating system,
application, firmware, driver, service or other) and the license type
(perpetual, subscription, OEM, volume, free, open source or other). An active
flag marks software currently in use.

The overview shows the number of installations per software, can be searched
by name and vendor, filtered by kind and sorted by the columns. Creating and
editing happen in a dialog.

As long as installations are still linked to a software item, it cannot be
deleted; remove the links first. This module concerns general software and
license management and is independent of the software registry in the ISMS.
