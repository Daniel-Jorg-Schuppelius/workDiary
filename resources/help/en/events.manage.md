Events combine date, location, responsibility, participants, reminders
and required resources.

First set period, visibility and event type. Then add participants,
roles, location, materials and reminders. For recurring events, review
the generated instances before invitations or reminders are sent.

Changes to time or location affect every invited person. Mark cancelled
events accordingly so history and notifications remain understandable.
