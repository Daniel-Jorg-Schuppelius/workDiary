If you have forgotten your password, request a reset link on the
"Forgot password" page. Enter your registered email address. For
security reasons, a generic confirmation is always shown, regardless of
whether an account exists for the address.

If a matching account exists, you receive an email with a link. Use
this link to set a new password. The link is valid for a limited time
only and can be used just once.

After a successful reset you are redirected to the sign-in page, where
you log in with the new password. If your account was previously linked
to the legacy system password, only the new password applies from now
on.
