Many parts of WorkDiary can be used without a mouse. Press `?` at any time
— outside an input field — to open the overview of all shortcuts. The same
overview is linked from this help text.

Shortcuts never fire while you are typing in an input field, a text box or
a select list, so they do not interfere with what you type.

Global shortcuts:

- `Ctrl`/`⌘` + `K` opens the global search (customers, projects, expenses,
  trips, employees …). Inside the search, pick a result with `↑`/`↓` and
  open it with `↵`.
- `Esc` closes the search or the dialog that is currently open.
- `?` shows the overview of all shortcuts.

Navigation shortcuts are short key sequences: first `g` (for "go to"), then
the target key within one second.

- `g` then `d` — diary
- `g` then `k` — customers
- `g` then `p` — projects
- `n` — new entry

Navigation shortcuts only appear when you are allowed to reach the target
through the menu as well. Without that permission the shortcut stays silent
and is not listed in the overview.
