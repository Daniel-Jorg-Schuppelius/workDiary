An exam offer is a club event of kind “exam” with system, target grades, examiners and the rule version, which is frozen when the offer is created. Later rule changes apply to new offers only.

**Candidates:** The leadership adds candidates with a target grade; members with access to “My club” request the exam themselves. Requirements are evaluated immediately for the exam start: if met, a self-request leads directly to admission with a seat; if not met, it stays a request without a seat which the leadership reviews. Admission and seat status are separate.

**Admission and exception:** If the rule requires leader approval, the leadership grants it on the candidate. With missing requirements, admission is possible only as an exception if the rule allows it, with a reason and a dedicated right. On exam day the check runs again; rescheduling the event or correcting a used attendance record flags affected candidates for review but removes nobody.

**Result:** Examiners of the offer or holders of the “examiner” right record passed, failed or no-show. Only “passed” awards the target grade, exactly once and with a reference to the exam; the eligibility report is frozen with the result. A failure removes no existing grade and resets no training time.

**Certificate:** Every valid grade has a PDF certificate with date, source, exam and confirming person. A revocation is printed visibly; the grading history remains authoritative.
