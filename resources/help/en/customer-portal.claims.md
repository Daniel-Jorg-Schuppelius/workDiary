Under **Complaints** you see the defects you reported, with status and decision. If evidence is missing, you can submit photos or documents later.

With **Register a return** you announce a return for a delivery or a device: reason, quantity, serial number if applicable, and photos. This creates a complaint with an announced return. As soon as a return label is available, download it from the complaint.

Please only send goods back once the return has been announced.
