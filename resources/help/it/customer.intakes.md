I clienti inviano richieste di stampa o IT con file nel portale clienti, alla voce **Richieste e ordini**. Ogni richiesta riceve un numero di pratica e compare qui con cliente, tipo di servizio, stato, data desiderata e responsabile. Le richieste aperte sono sempre elencate; quelle chiuse sono limitate al periodo nell'intestazione.

Come lavorare su una richiesta:

- **Assegna** prende in carico la richiesta; passa a «In lavorazione».
- **Fai una domanda** invia al cliente una domanda con file. La richiesta attende quindi la sua risposta; risposta o file aggiuntivi riprendono la lavorazione.
- **Nota interna** resta in azienda: il cliente non vede mai la nota né i suoi file.
- **Preventivo**: crei un nuovo preventivo o colleghi uno esistente del cliente. Dopo approvazione e invio il cliente decide nel portale; colleghi di nuovo una versione rivista: un consenso precedente non vale mai per un'altra versione.
- **Trasferisci** crea l'ordine di stampa o il ticket dopo l'accettazione. Un'accettazione parziale richiede un allineamento documentato dell'ambito. Trasferimenti ripetuti o simultanei non creano una seconda pratica.
- **Rifiuta** richiede una motivazione che il cliente leggerà. Non è più possibile dopo l'accettazione di un preventivo.

Dopo il trasferimento fa fede la pratica operativa; il cliente ne vede lo stato. Con **Apri caricamento** il cliente può allegare altri file alla richiesta trasferita. Se un'e-mail al cliente non va a buon fine, la richiesta mostra un avviso: dati e decisioni salvati restano invariati.

**Link di caricamento (Nextcloud):** se il plugin Nextcloud è configurato con credenziali proprie per il canale di caricamento, il cliente apre sulla richiesta un link di caricamento con password. WorkDiary acquisisce i nuovi file ogni 15 minuti o con «Recupera ora», li controlla come i caricamenti del portale e revoca il link dopo l'ultima acquisizione non appena la richiesta non accetta più file o il link scade. Gli errori compaiono sul link e nella cronologia; i file restano inoltre in Nextcloud.
