I token API permettono a programmi esterni di accedere all'interfaccia
di WorkDiary a suo nome senza usare la password. Alla creazione assegni
un nome per riconoscere lo scopo o il dispositivo. Il valore del token
viene mostrato una sola volta subito dopo la creazione: lo copi subito
e lo conservi in modo sicuro, perché non potrà più essere visualizzato.
Un token è una chiave di accesso completa al suo account: non
lo condivida mai e, in caso di sospetto abuso o se non serve più,
lo revochi immediatamente.
