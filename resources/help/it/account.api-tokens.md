I token API permettono a programmi esterni di accedere all'interfaccia
di WorkDiary a tuo nome senza usare la password. Alla creazione assegni
un nome per riconoscere lo scopo o il dispositivo. Il valore del token
viene mostrato una sola volta subito dopo la creazione: copialo subito
e conservalo in modo sicuro, perché non potrà più essere visualizzato.
Un token è una chiave di accesso completa al tuo account: non
condividerlo mai e, in caso di sospetto abuso o se non serve più,
revocalo immediatamente.
