Veranstaltungskategorien klassifizieren Veranstaltungen und Termine. Jede
Kategorie hat eine Bezeichnung, eine Farbe und optional eine Beschreibung
und liefert die fachliche Einordnung für die Veranstaltungsverwaltung.

Kann eine Kategorie einen Nachweis erfordern, lässt sich die
Zertifikatspflicht aktivieren und eine Gültigkeitsdauer in Monaten
hinterlegen. Erinnerungs-Vorlaufzeiten steuern, wann auf ablaufende
Nachweise hingewiesen wird.

Inaktive Kategorien bleiben bestehen, werden aber nicht mehr zur Auswahl
angeboten. Die Bezeichnung erzeugt automatisch einen Kurznamen für die
interne Zuordnung.
