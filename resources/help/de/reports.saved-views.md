Gespeicherte Ansichten machen aus einer eingestellten Auswertung einen
benannten 1-Klick-Einstieg: Auswertung öffnen, Filter setzen, die URL aus
der Adresszeile hier einfügen und benennen — fertig.

Ansichten sind zunächst persönlich. Mit „Teilen" werden sie für die ganze
Organisation sichtbar: So schauen alle auf dieselbe Zahlenbasis (etwa das
amtliche Monats-Reporting), statt Filter individuell nachzubauen.

Gespeichert werden nur interne Auswertungs-Seiten; Erstellerinnen und
Administratoren können Ansichten teilen, zurückziehen und löschen.
