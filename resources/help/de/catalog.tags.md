Tags sind eine generische Verschlagwortung, die sich an verschiedene
Entitäten anhängen lässt, etwa an Tagebucheinträge, Schichten oder
Zuweisungen. Jeder Tag hat einen eindeutigen Namen und optional eine Farbe.

Legen Sie einen aussagekräftigen Namen fest; der Name muss eindeutig sein. Über
die Farbe lassen sich Tags in Listen und an Einträgen optisch hervorheben.
In der Übersicht sehen Sie, wie oft ein Tag bereits verwendet wird.

Vermeiden Sie Dubletten mit nur leicht abweichender Schreibweise, damit die
Verschlagwortung auswertbar bleibt. Nicht mehr benötigte Tags können
gelöscht werden; die Zuordnungen werden dabei entfernt.
