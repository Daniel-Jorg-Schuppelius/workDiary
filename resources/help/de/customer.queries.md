Kunden stellen über das Portal bzw. den **Signaturlink** Rückfragen zu einem
vorgelegten Vorgang (Protokoll, Abnahme, Auftrag). Jede Rückfrage landet hier
als nachvollziehbarer Eintrag und löst eine Benachrichtigung an die
zuständige Rolle aus.

So arbeiten Sie mit Rückfragen:

- **Offene** Rückfragen stehen oben. Mit **Antworten** hinterlegen Sie eine
  interne Antwort; sie wird dem Kunden über denselben Link sichtbar.
- Mit **Schließen** markieren Sie eine erledigte Rückfrage, ohne sie zu
  beantworten (z. B. telefonisch geklärt).

**Freigabe und Ablehnung:** Über den Signaturlink kann der Kunde den Vorgang
auch **ablehnen**. Eine Ablehnung verlangt eine Begründung; gemeldete Mängel
werden automatisch als **Offene Punkte** (Quelle „Kunden-Ablehnung",
kundensichtbar) am betroffenen Auftrag bzw. Protokoll erfasst. Freigabe wie
Ablehnung werden mit Zeitstempel revisionssicher protokolliert.
