Mit API-Token können externe Programme in Ihrem Namen auf die
WorkDiary-Schnittstelle zugreifen, ohne Ihr Passwort zu verwenden.
Beim Anlegen vergeben Sie einen Namen, der Ihnen hilft, das Token später
einem Zweck oder Gerät zuzuordnen.

Der eigentliche Tokenwert wird nur ein einziges Mal direkt nach der
Erstellung angezeigt. Kopieren Sie ihn sofort und bewahren Sie ihn sicher auf,
denn er lässt sich später nicht erneut einsehen. In der Übersicht
sehen Sie nur Name und Erstellungszeitpunkt Ihrer bestehenden Token.

Wichtig: Ein API-Token ist ein vollwertiger Zugangsschlüssel zu Ihrem
Konto. Teilen Sie es niemals und übertragen Sie es nur über sichere Wege. Bei
Verdacht auf Missbrauch oder wenn ein Token nicht mehr gebraucht wird,
widerrufen Sie es umgehend; ein widerrufenes Token kann sofort nicht mehr
verwendet werden.
