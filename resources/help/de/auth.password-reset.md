Haben Sie Ihr Passwort vergessen, fordern Sie über die Seite „Passwort
vergessen" einen Link zum Zurücksetzen an. Geben Sie dazu Ihre
hinterlegte E-Mail-Adresse ein. Aus Sicherheitsgründen wird stets eine
allgemeine Rückmeldung angezeigt, unabhängig davon, ob zur Adresse ein
Konto existiert.

Existiert ein passendes Konto, erhalten Sie eine E-Mail mit einem Link.
Über diesen Link vergeben Sie ein neues Passwort. Der Link ist nur für
eine begrenzte Zeit gültig und kann nur einmal verwendet werden.

Nach erfolgreichem Zurücksetzen werden Sie zur Anmeldung
weitergeleitet, wo Sie sich mit dem neuen Passwort anmelden. War Ihr
Konto zuvor noch mit dem Altsystem-Passwort verknüpft, gilt ab jetzt
ausschließlich das neue Passwort.
