## Nachträglich umgesetzt (Empfehlungen aus dem Audit)

- **C (mittel) – Attachment-Upload an Edit-Recht gekoppelt:** `AttachmentController::store`
  (generischer Pfad, nicht der separat autorisierte Branding/Avatar-Pfad) _und_
  `Api/AttachmentController::store` rufen jetzt `Gate::authorize('update', $parent)`.
  Anhängen erfordert damit das Bearbeiten-Recht am Trägerobjekt (nicht nur Sicht­
  barkeit). Hinweis: reguläre User können nicht mehr an Objekte anhängen, die sie
  nicht bearbeiten dürfen (z. B. org-verwaltete Assets ohne `asset.update`).
- **Chat-Upload-MIME (niedrig):** `Chat/MessageController::attach()` prüft nun
  zusätzlich den serverseitig erkannten MIME-Typ gegen eine Allow-List (`ALLOWED_MIMES`).
- **Toggl-Import-Pfad (niedrig):** `TogglController` beschränkt den Admin-`path`
  über `safeImportPath()` (realpath-Prefix) auf erlaubte Basisverzeichnisse
  (`plugins.toggl.export_path` + `storage/app/toggl-imports`).
- **Login-Timing/Enumeration (niedrig):** `LegacyUserProvider::retrieveByCredentials`
  führt bei unbekanntem/abgelehntem Login einen Dummy-bcrypt-Check aus
  (`equalizeTiming()`) → konstante Antwortzeit gegen Enumeration.
- **Adress-PII vollständig verschlüsselt:** `ContactAddress` verschlüsselt jetzt
  auch `zip`/`city` (zuvor nur `street`/`supplement`); Spalten via Migration auf
  `TEXT` erweitert (nur MySQL/Postgres; SQLite erzwingt keine Länge),
  `security:encrypt-existing` deckt die Felder mit ab.

## Verifiziert sauber

- Mandantentrennung (alle Models gebunden bzw. dokumentierte Bypässe mit explizitem
  `organization_id`-Filter), Org-Switch nur für Admins, keine Impersonation.
- Keine SQL-Injection (alle `*Raw`-Queries mit Bindings), keine Command-Injection,
  kein `unserialize` auf Nutzerinput, kein echtes SSRF (Hosts aus Config), kein
  Zip-Slip (Upload-Pfade gehärtet).
- XSS: zentraler `ChatText`-Renderer escaped-first (Attribut-/Codeblock-Ausbruch
  per Test ausgeschlossen); alle `{!! !!}` geprüft (escaped/kuratiert); JS nutzt
  `textContent`/`escapeHtml`.
- CSRF aktiv (nur Backup-Heartbeat ausgenommen), Session-Regeneration beim Login,
  Reset-Tokens gehasht + ablaufend + Einmalgebrauch, API-Tokens gehasht (Sanctum),
  Reverb-Secret serverseitig, kein Secret-Logging, `APP_DEBUG` default false.
- Chat-Schreibrouten gedrosselt (`messages.store` 120/min; react/pin/forward/star/
  remind/vote 240/min), Broadcast-Channels per Sqid + Mitgliedschaftsprüfung.
