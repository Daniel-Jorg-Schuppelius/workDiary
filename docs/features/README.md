# Feature-Roadmap

Diese Feature-Roadmap hält Produktideen fest, bevor sie in konkrete GitHub
Issues zerlegt werden. Die Dateien beschreiben das fachliche Ziel, den
Differenzierungswert und den MVP-Umfang. GitHub Issues sollten später auf die
jeweilige Feature-Datei verlinken.

Der entwicklungsnahe Zuschnitt für eine erste Version liegt in
[000 Umsetzungsplan MVP](./000-umsetzungsplan-mvp.md). Dieser Plan bündelt die
Roadmap in Phasen, Epics und konkrete Issue-Vorschläge.

Ein importierbarer GitHub-Issue-Backlog mit Titeln, Labels, Quellen und
Definition-of-Done steht unter
[GitHub-Issue-Backlog MVP](./github-issues-mvp.md).

## Statuswerte

- `Proposed`: fachlich beschrieben, noch nicht als Umsetzung geplant.
- `Planned`: priorisiert und in GitHub Issues zerlegt.
- `In Progress`: Umsetzung läuft.
- `Done`: MVP ist umgesetzt und dokumentiert.

## Arbeitsweise

1. Feature-Datei fachlich schärfen.
2. MVP in kleine GitHub Issues zerlegen.
3. Issue-Links in der Feature-Datei nachtragen.
4. Nach Umsetzung Status und Dokumentation aktualisieren.
